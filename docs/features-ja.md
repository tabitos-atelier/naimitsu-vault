## パスワードを超えた機密情報の金庫

| 機能                     | 説明                                                                                                                                                                                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ファイル暗号化保管・ビューワ**     | 画像・PDF・証明書（.pfx/.pem/.cer）・SSH 鍵・GPG 鍵・OpenVPN 設定・サービスアカウント JSON・XML・Markdown・SQL・設定ファイル（YAML/TOML/INI 等）・ライセンスファイル・圧縮ファイル（ZIP/7z/RAR 等）を AES-256-GCM で暗号化保存。証明書は Subject/有効期限/拇印を専用表示、JSON/XML/Markdown/SQL/設定ファイルはシンタックスハイライト表示、ZIP は展開せずに中身のファイル一覧（パス・サイズ）を確認可能。 |
| **画像ギャラリー（共有プール方式）** | 画像を「プール」として管理し、複数の機密情報から同じ画像を共有。HMAC-SHA256 による重複排除でデータ容量を節約し、元ファイルの更新日も厳密に記録。                                                                                                                                                                                      |
| **ダイアログフリー即時自動保存**     | データの編集離脱時やページ遷移、アプリを閉じる際に、煩わしい「保存しますか？」の確認ダイアログを完全放逐。未確定の編集内容は入力欄からカーソルが離れたときに自動で下書き領域へ隔離保存され、いつでも安全に作業を再開可能。現在のデータと下書きの差分を並べて比較・確認できる専用の検証機能も搭載。                                                                                                             |
| **タイムマシン（3世代ローテーション）** | パスワードやテキストを現在・1世代前・2世代前の3世代で暗号化保持。**どの世代を復元しても「上書き」によるデータ消失は起こらず、3つのデータが循環（ローテーション）するだけ**の絶対安心設計。※意図しない履歴閲覧ログの記録や復号された内容の露出を防ぐため、他の画面からタイムマシンに戻るたびに選択状態は安全に初期化されます。                                                                                                                                                       |
| **保管庫分離＆緊急アクセスコード**    | プライベート・仕事・趣味など、用途に応じて最大3個の保管庫を切り替えて運用可能。各保管庫はマスターパスワードを含めて完全に独立。4桁PINで保護されたQRコードの緊急アクセスコードを発行、印刷して物理金庫などに保管しておけば、本人に不測の事態が生じた際、家族が**閲覧専用モード**で内容を引き継げる（マスターパスワードの再設定・回復は不可）。                                                                                        |
| **カスタムフィールド＆ドラッグ並べ替え** | 固定の入力欄に収まらない項目を「テキスト」または「パスワード（マスク表示）」として自由に追加。グリップアイコンをドラッグして表示順を直感的に並べ替え可能。                                                                                                                                                              |
| **改ざん不可の監査ログ**         | すべての操作を暗号化して自動記録（180日保持）。削除も書き換えもできない証跡が、「いつ・何を・どうしたか」を記憶の代わりに保持し続ける。                                                                                                                                                                                               |
| **2段階認証（2FA）統合**       | QR コードのスクリーンキャプチャ、またはセットアップキー（TOTP シークレット）の直接入力で設定を即時取り込み。パスワードと2FAコードを同じ場所で管理し、設定時の回復キー画像・PDFもその場で同時暗号化保管。PCの時刻同期ができないオフライン環境でも運用できるよう、現在のコードに加えて前後1周期分のコードも小さく併記表示し、時刻ズレによる認証失敗を防止。                                                                                    |
| **ダッシュボード**            | 保管庫全体の状況を1画面で把握できるホーム画面。機密情報・添付ファイルの総数やデータベースサイズを表示し、直近の監査ログもその場で確認可能。期限切れアラートやセキュリティ診断の結果もここに集約され、各項目はクリックひとつで該当画面へ直接ジャンプできる。                                                                                                                                      |
| **有効期限アラート**           | ライセンスや証明書の更新忘れを未然に防止。機密情報は30日以内（橙）、期限切れ（赤）を自動警告。証明書ファイル（PKCS#12・X.509 DER・PEM の各形式）は90日前から警告。プロフィールの身分証項目（名称を自由編集できる第1〜第3枠）は、初期設定の身分証・免許証（第1・第2枠）は60日前、パスポート（第3枠）は90日前から自動で警告アラートを表示。                                                                               |
| **プロフィール管理**           | 氏名・住所・身元確認情報（自由に名称変更できる3つの身分証枠）などの個人識別情報を、通常の機密情報とは完全に分離された専用画面で一元管理。スキャン画像やPDFも枚数制限なく添付可能。                                                                                                                                                                         |
| **自動修復（予備データからの復旧）**  | アプリの強制終了や不意の電源断でデータベースが破損した場合でも、次回起動時に直前の正常な状態（バックグラウンドで維持される二重の予備コピー）へと自律的に巻き戻し復旧。※クラッシュ直前の未保存データは救出できないが、金庫全体の完全破損を防ぐ。                                                                                                                                             |
| **ソフト削除（30日保護）**       | 削除した機密情報・添付ファイルは即座に物理消去されず、30日間ゴミ箱で保護。誤操作による喪失を防ぎ、手動での完全消去にも対応。この30日間は機密情報がタイムマシン画面、添付ファイルがギャラリー画面の削除済みフィルターから、それぞれいつでも復元可能。                                                                                                                                                                               |

### 制限事項

- TOTP コードは、QRコードの `otpauth://` URI から読み取った場合、または `otpauth://` の URI をセットアップキーの入力欄へ貼り付けた場合に限り、6桁・8桁コード、SHA-1/SHA-256/SHA-512、カスタム周期（60秒等）といった RFC 6238 標準外のパラメータにも対応します。キーだけを手入力した場合は、6桁・30秒・SHA-1 になります。未対応のパラメータ（例: 10桁、MD5）を含む URI は、誤ったコードが生成されないよう、取り込まずに拒否します。
- PDF プレビューは先頭 100 ページまでの表示に制限されます（メモリ圧迫・表示のフリーズを防ぐための上限）。
- 圧縮ファイルのうち、ビューワで中身のファイル一覧（パス・サイズ）を表示できるのは ZIP 形式のみです。7z/RAR/TAR 等は暗号化保存のみ対応し、プレビューは非対応です。ZIP 内のファイル数が 2,000 件を超える場合、一覧表示は先頭 2,000 件までに制限されます（メモリ圧迫・表示のフリーズを防ぐための上限）。

## シンプルに使える

| 機能                   | 説明                                                                                                                                                                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Windows Hello 対応** | 指紋・顔認証・PIN による生体認証でスマートにロック解除。                                                                                                                                                                                                                                     |
| **テーマ切り替え（ライト・ダーク）** | 明るい部屋で見やすいライトモード、目に優しいダークモード、Windows の設定に自動で合わせるシステムモードを搭載。Windows 11 に自然に溶け込む洗練されたデザイン。                                                                                                                                                                           |
| **キーボード自動入力**        | クリップボードを一切経由せず、直前にアクティブだったウィンドウ（ブラウザのログインフォーム等）へユーザー名・パスワードを直接入力。                                                                                                                                                                                                  |
| **クリップボードの自動保護**     | コピーしたパスワード等は Windows 標準の「クリップボード履歴（Win+V）」や他デバイスとの同期から自動的に除外され、30秒後に自動消去。                                                                                                                                                                                          |
| **画面キャプチャ保護**        | スクリーンショットや画面共有ソフトによる撮影を防止（既定でオン）。設定画面からいつでもオフに切り替え可能。                                                                                                                                                                                                              |
| **サイトアイコンの自動取得**     | 既定はオフ。オンにするとURLからドメイン名を外部送信してファビコンを取得するため、ゼロナレッジ原則とインターネットに接続できない環境での利用を優先し、初期状態では通信を発生させない設計。設定画面からオンにすれば、機密情報の一覧にサイトのアイコンを表示できる。登録先サイトへ直接アクセスすることはなく、DuckDuckGoのアイコンキャッシュAPI経由でのみ取得する。そのAPI側に未登録のドメイン（開設直後のサイト・独自ドメイン等）はアイコンが表示されないことがあるが、これは仕様どおりの挙動であり不具合ではない。 |
| **大画面パスワードプレビュー**    | 目玉ボタンひとつで、数字・記号を色分けした大きな文字で表示。「0」と「O」の見間違いによるロックアウトを根絶。                                                                                                                                                                                                            |
| **オートバックアップ**        | 機密情報（機密情報・添付ファイル・プロフィール）を保存・削除すると、指定したローカルフォルダへ暗号化 DB を丸ごと自動バックアップ。変化がなければ実行されないため、世代を無駄に消費しません。OS の同期クライアントで連携済みのクラウドストレージ用フォルダも保存先に選べますが、アプリ自身がインターネット経由でクラウドへ送信することはありません。設定変更だけでは実行されないため、PC 移行時など設定情報も含めた完全なスナップショットが必要な場合は、設定画面から手動バックアップを実行してください。 |
| **エクスポート・インポート**     | CSV/JSON 形式（暗号化なし）でのインポート・エクスポートに標準対応。データ仕様を完全公開（[エクスポート・インポート フォーマット仕様](import-export-format-ja.md)）しているため、他ツールからの移行も容易。プロフィールなどの個人識別情報は、ファイル漏洩時の身元特定リスクを最小化するためエクスポート対象から意図的に分離。                                                                                                                                 |
| **多言語対応・カスタムロケール**   | 英語・日本語に標準対応。ロケールファイル（JSON）をエクスポートし、編集して再インポートすることで任意の言語を追加できます。これを応用し、方言や業界用語、ゲーム風UIといった自由なカスタマイズも可能。AIに「〇〇風に書き直して」と指示するだけで簡単に自作できます。詳細は [Languages - カスタムロケール](locale-guide-ja.md) を参照。                                                                                                                              |
| **お気に入り・セキュリティ診断**   | スターフィルターで重要エントリに瞬時アクセス。パスワード入力時は強度バーがリアルタイムに堅牢性を評価。ダッシュボードでは保管庫全体のパスワード強度（zxcvbn）や危険な使い回しを一括スキャンして可視化。                                                                                                                                                             |

## データの保存形式

機密情報は SQLite データベースに保存されます。`data\` フォルダには、最大3個の保管庫を管理する統合データベース（`NaimitsuVault.nkdb`）と、保管庫ごとに暗号化された SQLite ファイル（ファイル名は48文字に匿名化）が並びます。本ドキュメント群で言う「金庫」は、これらをまとめたアプリの暗号化ストレージ全体を指す総称です。

フォルダの場所は配布形態によって異なります。README の [配布形態](../README-ja.md#配布形態) を参照してください。
