## A Vault for Confidential Information, Beyond Passwords

| Feature                                         | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Encrypted file storage & viewer**             | Encrypts images, PDFs, certificates (.pfx/.pem/.cer), SSH keys, GPG keys, OpenVPN configs, service account JSON, XML, Markdown, SQL, config files (YAML/TOML/INI, etc.), license files, and archives (ZIP, 7z, RAR, etc.) with AES-256-GCM. Certificates get a dedicated view showing subject, expiry, and thumbprint; JSON/XML/Markdown/SQL/config files get syntax highlighting; ZIP contents can be browsed as a file list (path and size) without extracting. |
| **Image gallery (shared pool)**                 | Images are managed as a shared "pool" that multiple secrets can reference. HMAC-SHA256 deduplication saves storage, and the original file's modification date is tracked precisely.                                                                                                                                                                                                                                                                               |
| **Dialog-free instant autosave**                | No more "Save changes?" prompts when you leave an edit, navigate away, or close the app. Unsaved edits are automatically staged into a draft area the moment the cursor leaves the input field, so you can always resume safely. A dedicated comparison view lets you check the diff between the current data and the draft.                                                                                                                                      |
| **Time Machine (3-generation rotation)**        | Keeps passwords and text across 3 encrypted generations — current, one generation back, two generations back. **Restoring any generation never causes data loss through overwriting — the three generations simply rotate.** An absolutely safe design by construction. Note: to prevent unintended audit logging of history views and decrypted content being left exposed, the selection is securely cleared each time you return to Time Machine from another screen.                                                                                                                                                                                   |
| **Vault separation & emergency access code**    | Switch between up to 3 vaults — private, work, hobby, whatever fits your use case. Each vault, including its master password, is fully independent. Issue an emergency access code — a QR code protected by a 4-digit PIN — print it and store it somewhere physical, so that if something ever happens to you, family can review its contents in **read-only mode** (it cannot reset or recover the master password).                                            |
| **Custom fields & drag-to-reorder**             | Freely add fields that don't fit the built-in ones, as either plain text or a masked password field. Drag the grip handle to reorder them.                                                                                                                                                                                                                                                          |
| **Tamper-proof audit log**                      | Every operation is encrypted and logged automatically (retained for 180 days). A trail that can't be deleted or rewritten keeps track of "what happened, when" — no memory required.                                                                                                                                                                                                                                                                              |
| **Two-factor authentication (2FA) integration** | Capture the setup key instantly by screen-capturing its QR code, or enter the setup key (TOTP secret) directly. Manage passwords and 2FA codes in the same place, and encrypt the recovery-key image or PDF from setup at the same time. Since PC clocks can't sync via NTP in fully offline environments, it also shows the previous and next step's codes in smaller text alongside the current one, so drift never causes a failed login.                                    |
| **Dashboard**                                   | The home screen for viewing your vault at a glance. See the total number of secrets and attached files, the database size, and your most recent audit log entries. Expiry alerts and security-scan results are also surfaced here, and every item is one click away from its target screen.                                                                                                                                                                       |
| **Expiry alerts**                               | Prevents missed renewals for licenses and certificates. Secrets are auto-flagged within 30 days of expiry (orange) and after expiry (red). Certificate files (PKCS#12, X.509 DER, and PEM) warn starting 90 days ahead. Profile identity fields (three freely relabeled slots) warn by default at 60 days ahead for slots 1–2 (ID card / driver's license) and 90 days ahead for slot 3 (passport).                                                               |
| **Profile management**                          | Manage personally identifiable information — name, address, and three freely relabeled identity document slots (national ID, passport, driver's license, etc.) — on a dedicated screen fully separated from ordinary secrets. Attach scanned images or PDFs without a page limit.                                                                                                                                                                                 |
| **Automatic repair (from a spare copy)**        | If the database is corrupted by an abrupt crash or power loss, the app automatically recovers to the last known healthy state (from redundant spare copies maintained in the background) on the next launch. Note: unsaved data from right before the crash cannot be retrieved, but this prevents total vault destruction.                                                                                                                                       |
| **Soft delete (30-day protection)**             | Deleted secrets and attached files aren't purged immediately — they sit in a trash bin for 30 days, protecting against accidental loss, with manual permanent deletion also available. During those 30 days, you can restore secrets from the deleted filter in the Time Machine screen, and files from the deleted filter in the Gallery screen.                                                                                                                                                                                        |

### Limitations

- TOTP codes support 6 to 8 digits, SHA-1/SHA-256/SHA-512, and a custom time step (e.g. 60 seconds) when read from a QR code's `otpauth://` URI or when an `otpauth://` URI is pasted into the setup key field — not limited to the RFC 6238 defaults. Typing only the key gives 6 digits, 30 seconds, and SHA-1. A URI with an unsupported parameter (for example 10 digits, or MD5) is rejected rather than imported, so the app never generates codes that silently differ from the service's.
- PDF preview is capped at the first 100 pages (a limit to prevent memory pressure and UI freezes).
- Among archive formats, only ZIP lets the viewer browse its file listing (path and size). 7z, RAR, TAR, and others are stored encrypted but cannot be previewed. If a ZIP contains more than 2,000 files, the listing is capped at the first 2,000 (a limit to prevent memory pressure and UI freezes).

## Simple to Use

| Feature                                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Windows Hello support**                   | Unlock smartly with fingerprint, facial recognition, or PIN.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Theme switching (Light / Dark)**          | Choose between high-contrast Light mode, eye-friendly Dark mode, or automatic OS System follow. A sleek, modern design that blends seamlessly into Windows 11.                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Keyboard auto-type**                      | Types your username and password straight into the previously active window (a browser's login form, for example) — no clipboard involved at any point.                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Automatic clipboard protection**          | Copied passwords are automatically excluded from Windows' built-in Clipboard History (Win+V) and cross-device sync, and wiped after 30 seconds.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Screen capture protection**               | Blocks screenshots and screen-sharing capture of the app window. On by default — toggle it off in Settings anytime.                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Site icon auto-fetch**                    | Off by default. Turning it on sends the domain name out to fetch each site's favicon, so the app stays silent on the network out of the box — in line with the zero-knowledge principle and friendly to environments with no internet access. Turn it on in Settings to show site icons in the secrets list. The app never contacts the site itself directly — it fetches icons only through DuckDuckGo's icon cache API. Domains that API hasn't indexed (newly launched sites, custom domains, etc.) may not show an icon; that's expected behavior, not a bug. |
| **Large-format password preview**           | One tap of the eye icon shows digits and symbols in large, color-coded text, eliminating lockouts caused by mistaking "0" for "O."                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Auto backup**                             | Automatically backs up the entire encrypted database to a local folder you choose whenever confidential content (secrets, attached files, profile) is saved or deleted. It skips silently when nothing changed, so it never burns through the backup rotation on its own. You can point it at a folder synced by an OS-level cloud client, but the app itself never sends anything to the cloud over the internet. A settings change alone doesn't trigger it — if you need a complete snapshot that includes settings too (e.g. before moving to a new PC), run a manual backup from Settings instead.                                                                                                                                                                                                                                                                                                                     |
| **Export / import**                         | Supports unencrypted CSV/JSON export and import out of the box. The data format is fully documented (see [Export / Import Format Specification](import-export-format.md)), so migrating from other tools is easy. Personally identifiable data such as profiles is intentionally excluded from exports to minimize identification risk if a file leaks.                                                                                                                                                                                                                                                                                 |
| **Multi-language support & custom locales** | Ships with English and Japanese out of the box. Export the locale file (JSON), edit it, and re-import to add any language you want. This also enables free customization — dialects, industry jargon, a game-style UI — just ask an AI to "rewrite this in the style of ___" and it's done. See [Languages - Custom Locales](locale-guide.md).                                                                                                                                                                                                                                                                       |
| **Favorites & security audit**              | Star-filter your important entries for instant access. A real-time strength bar evaluates password robustness as you type. The Dashboard runs a batch scan across the entire vault for password strength (zxcvbn) and dangerous reuse.                                                                                                                                                                                                                                                                                                                            |

## Where Your Data Is Stored

Your secrets are stored in SQLite databases. The `data\` folder holds one unified database (`NaimitsuVault.nkdb`) that manages up to 3 vaults, plus one encrypted SQLite file per vault (its filename anonymized to 48 characters). Where these documents say "vault," it's shorthand for that whole encrypted storage — the unified database and its vaults together.

The folder location depends on the distribution format — see [Distribution Formats](../README.md#distribution-formats) in the README.
